## 1. 한 줄 소개

인천 미추홀구 원룸의 동·유형·면적·보증금·건축년도를 넣으면, 실제 계약 데이터로 학습한 AI가 **적정 월세 범위**와 **비슷한 실제 계약 중 위치**를 보여주고 저렴 / 적정 / 비쌈을 판정하는 웹 서비스입니다.

## 2. 해결하려는 문제

- 원룸·다가구는 아파트와 달리 시세를 알기 어렵고, 보증금과 월세 조합이 제각각이라 비교는 더 어렵습니다.
- 정부의 안심전세앱은 전세 위험 진단이 중심이라 "이 월세가 적정한가"에는 답하지 않습니다.
- 처음 방을 구하는 대학생은 비싼 계약을 해도 알아채기 어렵습니다.

**대상:** 학교 근처 원룸을 구하는 대학생, 사회초년생

## 3. 기능과 진행 상태

| 우선순위 | 기능 | 상태 |
|---|---|---|
| 필수 | 적정가 예측 (AI 적정 범위) | ✅ 완료 |
| 필수 | 가격 신호 (저렴 / 적정 / 비쌈) | ✅ 완료 |
| 필수 | 예측 성적표 공개 | ✅ 완료 |
| 필수 | 근거 거래 표시 (비슷한 실제 계약 N건 중 위치, 분포 차트, 목록) | ✅ 완료 |
| 추가 | 건축물대장 정보 반영 (연립다세대, 지번 입력) | ⏸ 팀 합의 대기 |
| 추가 | 조건 환산 ("보증금 바꾸면 월세 얼마?", 전환율 공식) | 7주차 예정 |
| 추가 | 쉬운 설명 (LLM이 "왜 비싼지" 문장 생성) | 7~8주차 예정 |
| 선택 | 계약 체크리스트 | 미정 |

## 4. 경쟁 서비스와 차별점 (10/6 직접 확인)

| 서비스 | 하는 일 | 우리와 겹치는가 |
|---|---|---|
| 안심전세앱 (HUG) | 매매시세 조회, 전세보증금 기준 위험진단 | 겹치지 않음. 월세 입력 칸 없음 |
| 직방 매물 화면 | 호가, 관리비, 면적, 층, 준공일, 지번 표시 | 겹치지 않음. 시세 대비 판단 없음 |
| 직방 AI중개사 | 대화로 "비싼가"에 답함 | **일부 겹침.** 근거 거래·건수 없음, "실제와 차이가 있을 수 있다" 안내 |
| 다방, 네이버부동산 | 확인 필요 | 확인 필요 |

**차별점:** 실제 계약 근거 + 숫자로 된 범위 + 정확도 공개

**시연 사례:** 직방 매물(용현동 16㎡, 보증금 300, 월세 32)
- 직방 AI중개사: "아주 비싼 편은 아니다"
- 우리 서비스: "AI 적정 범위 31~44만 원, 비슷한 실제 계약 310건 중 하위 28%" (관리비 별도)

## 5. 데이터

| 데이터 | 내용 | 비고 |
|---|---|---|
| 전월세 실거래가 3종 (국토부, 공공데이터포털) | 단독/다가구, 연립다세대, 오피스텔 | 미추홀구(28177), 2023.10~2026.09 |
| 건축물대장 표제부 (국토부 건축HUB) | 지상층수, 승강기, 주차, 세대수, 연면적, 용적률, 사용승인일 | 연립다세대·오피스텔만 연결 가능 |

**정제:** 원본 20,242건 → 전세 제외 12,759 → 갱신 계약 제외 12,126 → 원룸(8~33㎡) 4,346 → 월세 이상값 제외 **4,312건**

**확인한 데이터 사실**
- 단독다가구에는 **층·지번이 없습니다.** 면적 칸 이름은 "연면적"이지만 실제로는 방 면적입니다(중앙값 35㎡).
- 소액 계약(보증금 6천만 원 이하 + 월세 30만 원 이하)도 원룸의 17% 들어 있습니다. 다만 미신고분은 알 수 없습니다.
- 최근 1~2개월은 신고 지연으로 건수가 적습니다.
- 월세는 3년간 단독다가구 약 10%, 오피스텔 약 13% 올랐습니다.
- 건축물대장은 시군구·법정동 코드 + 본번·부번으로 조회합니다. 미추홀구 법정동 코드(뒤 5자리)는 숭의 10100, 용현 10200, 학익 10300, 도화 10400, 주안 10500, 관교 10600(미확인), 문학 10700입니다.
- 건축물대장의 0 중 일부는 "기록 안 됨"입니다. 용적률 0인 건물이 54곳, 세대수 0인 건물이 29곳(오피스텔은 '호'로 셈)이라 빈칸으로 처리했습니다.

## 6. 방법

| 단계 | 내용 | 이유 |
|---|---|---|
| 시간 분할 | 2023.10~2026.02로 학습, 2026.03~08로 시험 (무작위 분할 금지) | 실제 서비스는 과거로 미래를 판단하기 때문 |
| 기준선 | 비슷한 조건(동·유형·면적·보증금 구간) 거래의 중앙값 | AI가 이것보다 나아야 의미가 있음 |
| 모델 | LightGBM 분위수 회귀 3개 (하위 20%, 중앙값, 상위 80%) | 범주·빈칸 처리 쉬움, 범위 예측 가능 |
| 범위 보정 | 검증 데이터(학습 기간 마지막 3개월)로 범위 폭 선택 | 실제 계약의 약 절반이 들어오는 범위가 되도록 |
| 건축년도 모를 때 | 건축년도 없이 학습한 별도 모델 사용 | 같은 모델에 빈칸을 넣으면 오차가 2배(8.8만 원) |
| 신호 규칙 | AI 범위로만 판정, 실제 계약 위치는 참고 표시, 근거 20건 미만이면 경고 | 화면에서 두 기준이 다르게 말하는 혼란 방지 |

## 7. 결과

### 7-1. 예측 성적표 (시험 741건)

| 방법 | 평균 오차 | ±5만 원 이내 | 범위 적중 |
|---|---|---|---|
| 전체 중앙값 하나 | 11.32만 원 | 29.8% | 76.7% (범위가 너무 넓음) |
| 비슷한 조건 중앙값 (기준선) | 5.91만 원 | 64.1% | 59.4% |
| **LightGBM (건축년도 앎)** | **4.49만 원** | 66.1% | 52.9% |
| LightGBM (건축년도 모름) | 4.97만 원 | 62.5% | 52.2% |

- 기준선 대비 오차 **24% 감소**
- 유형별: 오피스텔 약 3만 원, 단독다가구·연립다세대 5~6만 원
- 중요한 정보: 건축년도 > 보증금 > 유형 > 면적

### 7-2. 건축물대장 연결 실험

- 연결: 335곳 중 329곳(98%)을 찾았고, 찾은 곳 전부 실거래 건축년도와 승인연도가 1년 이내로 일치(100%)
- 효과 (0 값 정리 후, 서로 겹치지 않는 두 시험 기간):

| 기간 | 유형 | 지금 오차 | 건물정보 추가 | 개선 | 95% 범위 |
|---|---|---|---|---|---|
| 2025.9~2026.2 | 연립다세대 | 6.56 | 5.64 | **0.92** | +0.22 ~ +1.54 |
| 2026.3~2026.8 | 연립다세대 | 5.46 | 4.72 | **0.75** | +0.08 ~ +1.42 |
| 2025.9~2026.2 | 오피스텔 | 4.50 | 4.33 | 0.17 | -0.01 ~ +0.35 |
| 2026.3~2026.8 | 오피스텔 | 2.99 | 3.04 | -0.04 | -0.20 ~ +0.12 |

- **연립다세대**는 두 기간 모두 미리 정한 기준(0.3만 원 이상, 범위 전체가 0보다 큼)을 충족했습니다.
- **오피스텔**은 효과가 없었습니다. 처음 보였던 효과는 "세대수 0"이라는 잘못된 값 때문이었습니다.
- 승강기는 예측에 거의 쓰이지 않았습니다. 층수가 같은 정보를 이미 담고 있기 때문으로 보입니다.

### 7-3. 보증금 역설

실제 거래에서는 보증금 500만 원까지 월세도 같이 오릅니다. 좋은 방이 보증금과 월세를 둘 다 높게 받기 때문으로 보입니다. 그래서 모델은 **진단용**으로만 쓰고, "보증금 바꾸면 월세 얼마?"는 전월세 전환율 공식으로 따로 계산합니다.

## 8. 확정된 결정

| 결정 | 이유 |
|---|---|
| 지역: 미추홀구, 원룸 8~33㎡, 유형 3종 | 학교 주변, 3년에 4,312건으로 충분 |
| 기간: 2023.10~2026.09, 갱신 계약 제외 | 갱신은 인상률 상한 때문에 시세보다 낮음 |
| 모델: LightGBM 분위수 회귀, 범위 하위 20%~상위 80% | 검증 데이터에서 실제 적중 51% |
| 신호는 AI 범위로만, 반올림 후 비교, 근거 20건 미만 경고 | 화면 혼란 방지, 근거 공개 |
| LSTM 사용 안 함 | 시계열 문제가 아님 |
| 조건 환산은 7주차, 전환율 공식으로 | 모델로 하면 보증금↑ → 월세↑로 나옴 |
| **(합의 대기)** 건축물대장은 연립다세대에만 적용 | `docs/팀합의_건축물대장_적용.md` 참고 |

## 9. 약점

### 아직 남은 약점

| 약점 | 영향 | 대응 |
|---|---|---|
| 관리비·옵션·역 거리 정보 없음 | 관리비를 올린 방을 "저렴"으로 잘못 볼 수 있음 | 화면에 "관리비 별도" 표시 |
| 단독다가구는 층·지번 없음 | 건물·층 차이 반영 불가, 건축물대장 연결 불가 | 한계로 명시 |
| 신고되지 않은 소액 계약 | 아주 싼 방은 덜 정확할 수 있음 | 한계로 명시 |
| 범위 경계 근처는 신호가 바뀔 수 있음 | 32만 원이 학습 데이터에 따라 저렴↔적정 | 하위 N%를 함께 표시 |
| 트리 모델은 미래 시점을 외삽 못 함 | 시세가 빨리 오를 때 약간 낮게 예측 | 한계로 명시 |
| 직방 AI중개사와 일부 겹침 | "직방 보면 되지 않냐" | 근거·범위·정확도로 차별화 |
| 자주 쓰는 서비스는 아님 | 방은 1~2년에 한 번 구함 | 수업 프로젝트로서는 감수 |

| 걱정했던 것 | 결과 |
|---|---|
